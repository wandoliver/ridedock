# Working name shortlist

The repository uses **Open Cycling Analytics** as a descriptive placeholder. Before a public release, check domains, package registries and trademarks.

- **RideLedger** — emphasizes durable, provider-neutral ride records.
- **Chainline** — short and cycling-native; likely needs careful trademark checking.
- **VeloScope** — suggests exploration and analysis.
- **Cadence Commons** — strongly communicates open community infrastructure.
- **Draftline** — evokes riding and longitudinal trends.
- **OpenRide Lab** — clear but generic.
- **RideFoundry** — fits a modular platform that produces analyses and features.

My preference is **RideLedger** for the data platform or **Cadence Commons** for the community/open-source identity. Neither name has been legally or commercially cleared.
